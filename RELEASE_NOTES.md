# TIT STRIPPER v0.1.0

Free channel strip: gate/expander, compressor and dynamic EQ in any order.

## Download
Download the zip for your system from the **Assets** list below:
- `TITSTRIPPER-Windows-VST3.zip`: Windows (VST3).
- `TITSTRIPPER-macOS-VST3.zip` and `TITSTRIPPER-macOS-AU.zip`: macOS (VST3 and AU). One universal build for Apple Silicon and Intel.
- `TITSTRIPPER-source.zip`: source code.

Unzip it and copy `TIT STRIPPER.vst3` to your VST3 folder (Windows: `C:\Program Files\Common Files\VST3`; macOS: `/Library/Audio/Plug-Ins/VST3`, AU: `/Library/Audio/Plug-Ins/Components`), then rescan plugins in your DAW.
Unsigned macOS builds: in Terminal run `xattr -cr "TIT STRIPPER.vst3"` (or `.component`).

## What's in it
- Gate/Expander + TIT COMP + TIT Q in one plugin, six possible module orders, On/Off per module.
- Whole-strip presets, shared external sidechain.
- Start-up order and Color default configurable from the menu or `config.txt`.

Free and open source (AGPLv3). No registration.
